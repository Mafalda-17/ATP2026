## Resumo
Aplicação para guardar e analisar registos do tempo. Em cada dia regista a data, a temperatura mínima, a temperatura máxima e a quantidade de chuva.

• Cria uma aplicação que coloca no monitor o seguinte menu de operações:

1- Adicionar registro à tabela;

2- Lista tabela;

3- Temperatura média;

4- Guardar tabela em ficheiros;

5- Carregar tabela do ficheiro;

6- Temperatura mínima mais baixa;

7- Amplitude Térmica;

8- Dia de maior precipitação;

9- Dias chuvosos;

10- Maior período consecutivo de dias secos;

11- Gráficos
            
0: Sair da aplicação
  
• No fim de executar a operação selecionada, a aplicação deverá colocar novamente o menu e pedir ao utilizador a opção para continuar;
