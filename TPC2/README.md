## Resumo
Criar um programa em Python para jogar o jogo "Adivinha o jogo"
O jogo tem que ter 2 modalidades: o computador pensa num número e o utilizador adivinha ou o utilizador pensa num número e o computador adivinha.

Quem pensou no número responde com Acertou, maior ou menor. 

Depois de acertar o número é necessário o programa imprimir o número de tentativas que quem adivinhou usou para acertar.
